# Registration and Login

This section addresses some of the most common issues users encounter during registration and login.

<hr/>

### What should I select as my Identity Provider?

Whenever possible, prioritize using your institution's identity provider, as this offers the most seamless and straightforward login experience. If your institution is not part of [CILogon](https://www.cilogon.org/), you have two alternative options:

- **[ORCID](https://orcid.org/)** — Requires an existing ORCID account. If you don't have one, create it in advance.
- **Google** — Log in using an existing Google account.

### What happens if I choose ORCID or Google as my Identity Provider?

- If you select **ORCID**, you'll get access to computing resources in addition to standard NDP features.
- If you select **Google**, you'll get access to most NDP features, but **not** computing resources.

### I selected ORCID as my provider, but later logged in with my institution using the same email — now I can't log in. What happened?

This creates a conflict in the identity management system: your account was originally validated through ORCID, not through CILogon (your institution's provider), so the system can't reconcile the two as the same identity.

If this happens to you, please [contact us](../contact.md) for help resolving the conflict.
